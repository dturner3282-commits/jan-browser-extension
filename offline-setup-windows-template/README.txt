Offline setup template (Windows)

This folder is a ready-to-fill template that you will copy to a USB drive on an online computer.
Do NOT place these files on any public computer or online storage.

Folder structure (fill these before copying to USB):
- installers/    -> Put LM Studio installer (.exe or .msi) and Jan installer (.zip or .exe)
- models/        -> Put Qwen-7B-Chat.gguf and all-MiniLM-L6-v2.gguf (exact file names)
- docs-samples/  -> Put a small PDF, one TXT and one MD file for quick offline testing

How to use:
1) On the online computer, download installers and model files and place them in the appropriate folders inside this template.
2) Copy the entire 'offline-setup-windows-template' folder to the root of a USB drive (see USB_COPY_INSTRUCTIONS.txt for steps).
3) Safely eject the USB and move it to the offline computer.

Important filename notes:
- Please name model files exactly: Qwen-7B-Chat.gguf and all-MiniLM-L6-v2.gguf
- Do not unzip or open model files on unknown machines.

When ready, insert USB into the offline computer and follow the offline setup checklist provided separately.
