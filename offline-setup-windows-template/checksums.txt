# SHA256 Checksums for offline-setup-windows-template

This file verifies the integrity of all files in the offline-setup template.

## How to verify on Windows:

PowerShell:
```powershell
$checksums = @{
  # Add checksums below after files are placed in the template
  # Format: "filename" = "sha256hash"
}

# Run this to verify a file:
$file = "Qwen-7B-Chat.gguf"
$computed = (Get-FileHash -Path $file -Algorithm SHA256).Hash
$expected = $checksums[$file]
if ($computed -eq $expected) { Write-Host "✅ OK" } else { Write-Host "❌ MISMATCH" }
```
